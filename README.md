# Transcritor Local CLI

Ferramenta de linha de comando para captura e transcrição local de reuniões no Windows 10/11.

## Dependências

- Windows 10/11
- Python 3.10+
- PyAudioWPatch (para captura WASAPI loopback e Microfone simultâneos)
- faster-whisper

## Instalação

```bash
pip install -r requirements.txt
```

## Uso

```bash
python main.py
```
